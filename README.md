# Roster Dashboard

Scaffolded Next.js app with Drizzle ORM (example) to satisfy issue #2.

Setup:

1. Copy `.env.example` to `.env` and update `DATABASE_URL`.
2. Install dependencies:

```bash
npm install
```

3. Run dev server:

```bash
npm run dev
```

4. Run migrations (after configuring DB):

```bash
npm run migrate
```
